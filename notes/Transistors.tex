 Topic 4: Transistors (BJTs) & DC Biasing
 Key Definitions
Bipolar Junction Transistor (BJT): A three-terminal semiconductor device (Emitter, Base, Collector) used for amplification and switching. It is fundamentally a current-controlled device.
Cut-off Region: The operating state where the base current is zero ($I_B = 0$). The transistor behaves like an open switch; no collector current flows ($I_C = 0$).
Saturation Region: The operating state where the transistor is turned on completely. The collector current reaches its absolute maximum limit, restricted only by external load resistors.
 Essential Formulas & Variables
Formula Variables Breakdown
$I_C = \beta \cdot I_B$ $I_C$: Collector output current ($\text{mA}$)$I_B$: Base input current ($\text{mA}$)$\beta$ ($h_{FE}$): Common-emitter current gain factor
$I_E = I_C + I_B$ $I_E$: Emitter current ($\text{mA}$)
$V_{BB} - I_B R_B - V_{BE} = 0$ Input Base Loop KVL formula$V_{BB}$: Base supply voltage ($\text{V}$)$R_B$: Base current-limiting resistor ($\Omega$)$V_{BE}$: Base-Emitter forward junction drop ($\approx 0.7\text{ V}$)
$V_{CC} - I_C R_C - V_{CE} = 0$ Output Collector Loop KVL formula$V_{CC}$: Collector main power rail ($\text{V}$)$R_C$: Collector load resistor ($\Omega$)$V_{CE}$: Collector-Emitter voltage drop ($\text{V}$)
 Top 3 Common Exam "Trap" Questions to Watch Out For:
Temperature Conversions: Always check if the question gives Celsius ($^\circ\text{C}$). Formulas like the intrinsic carrier equation must use absolute temperature in Kelvin ($K$).
Parallel Loads: In filter/rectifier questions, if multiple resistors are connected across the output, calculate their equivalent parallel resistance ($R_{\text{eq}}$) first before using the ripple formulas.
Diode Voltage Drops: Pay close attention to whether a question specifies ideal diodes ($0\text{ V}$ drop) or practical silicon diodes ($0.7\text{ V}$ drop) when calculating maximum peak loop outputs.
